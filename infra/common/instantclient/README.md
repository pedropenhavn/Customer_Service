## Arquivos do Oracle Instant Client

Você precisa baixar os arquivos do Oracle Instant Client e colocá-los no diretório `infra/instantclient`. Siga as instruções abaixo para baixar os arquivos:

1. **Pacote Basic Lite**

    - **Nome do Arquivo:** `instantclient-basiclite-linux.x64-19.12.0.0.0dbru.zip`
    - **URL para Download:**
      ```plaintext
      https://download.oracle.com/otn_software/linux/instantclient/1912000/instantclient-basiclite-linux.x64-19.12.0.0.0dbru.zip
      ```
    - **Descrição:** Este pacote contém os arquivos essenciais necessários para executar o SQL*Plus e outras aplicações cliente Oracle.

2. **Pacote SDK**

    - **Nome do Arquivo:** `instantclient-sdk-linux.x64-19.12.0.0.0dbru.zip`
    - **URL para Download:**
      ```plaintext
      https://download.oracle.com/otn_software/linux/instantclient/1912000/instantclient-sdk-linux.x64-19.12.0.0.0dbru.zip
      ```
    - **Descrição:** Este pacote contém arquivos adicionais necessários para desenvolver aplicações Oracle.
